Official product documentation and customer support for Equipped Browser Daybreak (iOS) and Muse Code (macOS).

Equipped Browser Daybreak (iOS)

Equipped Browser Daybreak is a local-first, agent-native web browser for iPhone featuring:

  • AI Model Router: Switch seamlessly between Apple On-Device (FoundationModels & NaturalLanguage), Apple Private Cloud Compute (PCC), and Keychain-backed BYOK HTTPS API endpoints.
  • Four Browser Chat Agents: Navigator, Researcher, Keeper (WebAuthn Level 3 Passkey Vault with ES256/Ed25519, largeBlob & PRF), and Shopper operating on live page DOM.
  • 3D Flippable Address & Agent Bar: Roll between the URL omnibox, Agent Console, and Security Controls (Safe Browsing, Parental Controls, HTTPS-Only Lockdown Mode).

Muse Code & Muse on Safari (macOS)

Muse Code is a native macOS agentic coding workspace featuring:

  • Built-In On-Device Workspace Agent: Open any local project folder and ask questions or inspect code immediately out-of-the-box with zero external setup or account required.
  • Multi-Session Threads, Git Diff Inspector & Integrated Terminal: Review side-by-side diffs, run workspace commands, and use voice dictation in a liquid-glass macOS interface.
  • Bundled Muse on Safari Web Extension: Enable Muse on Safari in Safari > Settings > Extensions to let your local Muse Code workspace inspect and navigate active Safari tabs over localhost.
