Equipped Browser Daybreak — Support

Equipped Browser Daybreak is a local-first, agent-native web browser for iPhone featuring the AI Model Router (On-Device, PCC Cloud, and Keychain BYOK API Key), four interactive browser chat agents (Navigator, Researcher, Keeper, Shopper) with live browser tools, W3C/Chrome Built-In AI Producer parity (window.LanguageModel & window.ai), WebAuthn passkeys, and a 3D rolling address bar.
