Privacy Policy — Equipped Browser Daybreak & Muse Code

Effective Date: November 7, 2026 · Publisher: Zunftmax UG (haftungsbeschränkt)

This Privacy Policy governs both Equipped Browser Daybreak (iOS / iPadOS) and Muse Code including the bundled Muse on Safari Web Extension (macOS), published by Zunftmax UG (haftungsbeschränkt).

Part I — Equipped Browser Daybreak (iOS)

1. Local-First Browser Storage

Equipped Browser Daybreak is a local-first web browser. By default, your browsing history, bookmarks, tab state, security preferences, and credentials are stored locally on your device using iOS UserDefaults and the iOS Keychain. Zunftmax UG collects no analytics, telemetry, or browsing history.

2. AI Model Router & Built-In Web AI

  • Apple On-Device (SystemLanguageModel & NaturalLanguage): Prompts and active tab DOM context are processed locally on your device using Apple FoundationModels and NaturalLanguage (NLTagger). No data leaves your device.
  • Apple Private Cloud Compute (PCC): When selected on supported Apple Intelligence devices, requests are routed through Apple FoundationModels under Apple’s Private Cloud Compute privacy architecture.
  • API Key (BYOK): Only if you explicitly configure your own third-party HTTPS API key in the Model Router, your chat prompt and active page excerpt (title, URL, headings, and text summary) are transmitted directly from your device over HTTPS to your configured endpoint. Your API key is stored exclusively in your on-device Keychain.

3. Passkeys, WebAuthn & Credentials

Passkeys (ES256/Ed25519) and saved credentials are stored exclusively in the iOS Keychain on your device and are never transmitted to Zunftmax servers.

Part II — Muse Code & Muse on Safari (macOS)

1. Local Workspace & Sandbox Operation

Muse Code is a local-first agentic coding environment for macOS. Project files, Git diffs, terminal sessions, and chat transcripts are stored locally on your Mac inside your user-selected workspace folders and local application container. No workspace files or code are sent to Zunftmax servers.

2. Built-In Workspace Agent & Optional External Harnesses

  • Built-In On-Device Workspace Agent: Runs locally inside the macOS App Sandbox using Apple FoundationModels, NaturalLanguage (NLTagger), and local file inspection without transmitting your code to external servers.
  • Optional User-Configured CLI / API Providers: If you optionally connect an external coding CLI or API key, prompts and workspace context you select are sent directly to that provider under your own credentials.

3. Muse on Safari Web Extension & Microphone Dictation

  • Muse on Safari Web Extension: Communicates exclusively over localhost / macOS App Group with the Muse Code desktop app on the same Mac so you can inspect or navigate active Safari tabs on demand. No browsing data is transmitted off your Mac.
  • Voice Dictation (Microphone & Speech Recognition): Audio captured when you press the microphone button is used solely for live voice-to-text transcription in the composer and is not recorded or stored by Zunftmax UG.

Data Retention, Deletion & Contact

You can clear transcripts, sessions, bookmarks, history, and stored credentials directly inside each app at any time, or remove all local data by uninstalling the application.

For privacy inquiries or support requests, contact Zunftmax UG (haftungsbeschränkt) at mac@devkeys.net.
